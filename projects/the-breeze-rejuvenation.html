01 — PROJECT NOTES

About this project

This project features structural steel canopy modelling for The Breeze Rejuvenation project by Sinarmas, comprising two canopy structures identified as CC3 and CB9.

CC3 features an architecturally curved canopy design, while CB9 adopts a straight configuration with varying column elevations, creating a descending structural profile.

Both structures were modelled using Tekla Structures and subsequently realized in the field, representing the structural modelling work for the project's construction.

02 — MODEL CONTENT

Technical details

The structural model was developed in Tekla Structures Educational 2026 and exported in IFC4 format for 3D model visualization and coordination.

The model represents the structural arrangement of both canopy structures, including primary and secondary steel members, supporting columns, and connection-related components.

The interactive model preview provides an overview of the structural geometry, framing configuration, and overall arrangement of the canopy structures.
