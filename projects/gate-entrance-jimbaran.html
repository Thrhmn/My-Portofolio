01 — PROJECT NOTES

About Gate Entrance – Jimbaran, Bali

This project features the structural steel modelling of a hotel entrance gate located in Jimbaran, Bali, developed for WKC.

The modelling work involved updating an existing IFC model based on the latest 2D drawings. The structure mainly uses large hollow steel sections, complemented by WF beams as supporting members.

The updated model was used for shop drawing preparation and released for construction. The structure was subsequently built on site.

02 — MODEL CONTENT

Technical preview

The 3D structural model was developed using Tekla Structures and exported in IFC4 format for model visualization and coordination.

The model represents the primary hollow steel members, WF beam framing, supporting columns, and associated connection components that define the overall entrance structure.

The interactive IFC preview provides an overview of the structural configuration, member arrangement, and connection details.
